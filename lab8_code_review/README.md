## Запуск

Из этой папки (JDK 17+, один файл — одна программа):

```
java DemurrageLegacy.java
java ShiftPlanLegacy.java        # ожидаемо: ConcurrentModificationException
java ShiftPlanFixed.java         # 12 проверок, все [OK]
```

В Colab — «Среда выполнения → Перезапустить и выполнить все».

## Что проверено

- Внешнее поведение на корректных данных сохраняется: characterizes-тест фиксирует `Иванов; Петров; `.
- Все `blocker` и `major` из `ReviewNotes.csv` устранены; соответствие зафиксировано в таблице прослеживаемости в ноутбуке.
- Некорректные входы (`need < 1`, нехватка бригад, `null`, пустая фамилия, отрицательные часы) приводят к `IllegalArgumentException` с сообщением, а не к `IndexOutOfBoundsException`.
- Статическое состояние (`SimpleDateFormat`, общий список) заменено на потокобезопасные аналоги; проверен параллельный вызов.
