# Лабораторная работа № 7 — паттерны GoF (вариант 11, «Путевое хозяйство»)

Исполнитель: **Киселев И. Д.**, группа **ГИ-41**, вариант **11**.

## Состав

| Файл | Назначение |
| --- | --- |
| `TariffAfter.java` | Образец Strategy: расчёт платы за перевозку (общий для всех вариантов) |
| `FactoryAfter.java` | Factory Method: создание дефектов рельсов (ГТ, ТШ, КП + новое УК) |
| `ObserverAfter.java` | Observer: оповещение об обнаруженном дефекте (ремонт, диспетчер, журнал + АСУ) |
| `strategy.puml` | Диаграмма классов Strategy |
| `factory.puml` | Диаграмма классов Factory Method |
| `observer.puml` | Диаграмма классов Observer |
| `Песочница_паттернов.ipynb` | Заполненный ноутбук Colab с ответами, кодом, выводами и самопроверкой |
| `outputs/` | Сохранённые выводы запуска всех программ и самопроверки |
| `selfcheck_report.md` | Вывод ячейки автоматической самопроверки |
| `pull_request_description.md` | Готовое описание pull request |

## Запуск

В Colab — «Среда выполнения → Перезапустить и выполнить все», либо локально (Java 11+) из этой папки:

```
java TariffAfter.java
java FactoryAfter.java
java ObserverAfter.java
```

Каждая программа печатает `[OK]` / `[FAIL]` и бросает `AssertionError` при неудачной проверке.
